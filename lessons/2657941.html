TEACHER GUIDE · 3D MODELING

Lesson 1: Design Your Own Currency

Join the Tinkercad class, then sketch a coin for the next lesson.

Today at a glance

First 10–15 minutes: get every student into your Tinkercad class. Next 5 minutes: model a coin sketch. Remaining time: draw, photograph, and submit. Save the last 5 minutes for upload help.

Materials: student computers, paper, pencils, and coloring tools.

Learning goal

Students will plan both sides of a coin and explain how one detail will change when the drawing becomes a 3D model.

TEKS:
  • §126.19(c)(12)(C) — select and use appropriate platform and tools, including selecting and using software or hardware to transfer data;

Evidence: photo of both sides and the existing 2–3 sentence reflection in Canvas. Students practice selecting a digital tool during class sign-in and transferring a photo during submission. No separate annotation sheet or login grade.

Before class: prepare Tinkercad

Before class: Create your Tinkercad class and post its join link or class code in Canvas. Test the link with the school Google sign-in route.

  1. To create a class, sign in with your teacher account and open Classes. Select Create new class, enter its name, grade/age, and subject, then select Create class.
  2. Open your class and select Class Code. Copy its join link or code and share it through Canvas. Each teacher uses their own class.
  3. Students join using their school Google accounts. You do not need to assign nicknames for this route. Use the class roster and designs view to check membership and see their work.

First 10–15 minutes: join with Google

  1. Have students open the Tinkercad class link you posted in Canvas. Project your class code if needed.
  2. A direct class link skips code entry. If students use Students with Class Code, they enter the code you provide and select Go to my class.
  3. Check that the welcome screen shows your class name. Under Other providers, select the Google G.
  4. Choose the student's school Google account and complete sign-in. Use Google again next lesson to return to the same designs.
  5. Check that each student appears in your class roster and can show their signed-in screen. Once checked, they begin the paper coin sketch.

Quick fixes: a nickname prompt means the student chose “Join with Student login.” Go back and choose Google. If the wrong account opens, switch to the school Google account and reopen the class link. If joining is incomplete, reopen the class link after Google sign-in. A student waiting for help can begin the paper sketch.

Model the coin sketch (5 minutes)

  1. Open Lesson 1: Design Your Own Currency. Point to the student-made front and back. Ask: “Where is the value? Which details connect the two sides?” Explain that the example shows a personal theme; today students use their own school symbols and school colors. Choose one simple detail to show how it could become raised or recessed in 3D.
  2. Draw two circles and label them Front and Back. Add one value, a simple school symbol, and a border. Use large, simple shapes students can model next lesson.
  3. Hold a real coin sideways if one is available. Explain: the paper drawing is flat; the model will have thickness. Point to a detail that could stick out or be pressed in.
  4. Say: “Today we draw our coin. Next lesson we build it in Tinkercad.” Leave the student assignment and examples projected during work.

Drawing and submission

Students draw both sides of one coin with a value, school details, and school colors. They upload a clear photo of both drawings to the existing assignment and answer the reflection in 2–3 sentences in submission comments. The existing extra-credit second coin stays optional.

Check while circulating: can you read the value, recognize a school symbol, and identify a detail that could have depth? If a design is too detailed, simplify the symbol. Color helps the paper plan; shape and height must still communicate in the 3D model.

Language support: coin / moneda; front / frente; back / reverso; value / valor; raised / elevado; recessed / hundido. Model: “My ___ will stick out because ___.” Students can use the Spanish tab and submission-help video already in the assignment.
