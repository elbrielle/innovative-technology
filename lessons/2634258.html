Create Your Own Interactive Pinball Game with Physics!

  • Español

🌌 Overview & Example

You will build an AR arcade game on the Merge Cube in Delightex - pinball, a marble maze, or something you invent.

🔗 Access Delightex:

🚀 Open Delightex

Remember: Sign in with Microsoft using your @stu.irvingisd.net email

🎮 Explore the Example Game:

Check out this Space Pinball game. Notice how physics and movement make it interactive.

⚙️ Understanding Delightex Physics

Delightex has built-in physics. You can:

  • Turn on gravity to make objects fall
  • Control how much objects weigh, roll, and bounce
  • Make platforms move when clicked

💡 Tip: Double-click any object and select "Physics" to see all the options.

📚 Tutorial & Project Requirements

Follow the activity worksheet and watch the tutorial to build a Merge Cube game like "Space Pinball".

✅ Project Requirements:

Your Delightex Merge Cube game must include:

  1. Use Physics - Enable the "Physics" option in Delightex
  2. At least 10 parts from the library (platforms, obstacles, decorations)
  3. Clear goal/objective - Example: move the ball from start to finish

Your game could be a marble maze, pinball, or any arcade game you invent.

🎥 Tutorial Video:

Watch this tutorial and follow along to build your AR pinball game:

⚠️ Important: physics script

To make physics run properly in your game, you MUST add this script:

Physics.realTime = true;

Add this in the script editor before testing your game.

⚔️ Optional Challenge

Finished early? Push it further:

🏆 Challenge Ideas:
  • Add multiple levels using the "change scene" feature
  • Add more physics properties to change how the game plays
  • Create moving obstacles using CoBlocks
  • Add a scoring system or timer

🎮 Build it, play it, then submit. 🌟

⚙️ Entendiendo la Física de Delightex

Delightex tiene física integrada. Puedes:

  • Activar la gravedad para hacer caer objetos
  • Controlar cuánto pesan, ruedan y rebotan los objetos
  • Hacer que las plataformas se muevan al hacer clic

💡 Consejo: Haz doble clic en cualquier objeto y selecciona "Física" para ver todas las opciones.

📚 Tutorial y Requisitos del Proyecto

Sigue la hoja de actividades y mira el tutorial para construir un juego de Merge Cube como "Space Pinball".

✅ Requisitos del Proyecto:

Tu juego Merge Cube de Delightex debe incluir:

  1. Usar Física - Habilita la opción "Física" en Delightex
  2. Al menos 10 partes de la biblioteca (plataformas, obstáculos, decoraciones)
  3. Meta/objetivo claro - Ejemplo: mover la bola desde el inicio hasta el final

Tu juego podría ser un laberinto de canicas, pinball o cualquier juego de arcade que inventes.
