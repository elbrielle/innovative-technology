Design a Smart Gadget: Need, Input, Process, Output

A gadget is not smart because it glows. It is smart when it receives information and does something useful with it.

BIG QUESTION / GRAN PREGUNTA: How can a gadget receive information and respond to a specific user need? / ¿Cómo puede un gadget recibir información y responder a una necesidad específica del usuario?
  • Time / Tiempo: one class period / un periodo de clase
  • You need / Necesitas: your comic, pencil, and coloring supplies / tu cómic, lápiz y materiales para colorear

  • Español

Learn: follow the information

A smart system has an input, a process, and an output. The process is the rule the gadget follows.

  • The input is the information or signal the gadget receives.
  • The process is what the gadget does with the input. It often follows an if-then rule.
  • The output is the action, sound, light, movement, or message the gadget produces.

Example: An automatic hand dryer detects hands nearby. If hands are detected, it turns on. Warm air is the output.

Words for today: user need · sensor · input · process · output

Student example: This page uses panels, labels, and arrows to show a gadget in action.

This older example does not label the full chain. Your Page 2 must label the user need, input, process, and output.

Choose the need before the gadget

Look back at Page 1. What problem matters to your hero? Choose one person or group affected by that problem. Your gadget should help that user do something they cannot do easily now.

Planning stem: "My user needs a way to ____ when ____."

Create Page 2

Include:

  • the gadget's name;
  • the user need or problem;
  • a labeled drawing;
  • at least one input;
  • a process, including an if-then rule when it fits; and
  • at least one output.
If you get stuck: Start with the signal. What could the gadget sense or receive: light, sound, movement, distance, temperature, a button press, or a message? Then decide what should happen next.

Trace the chain

Show your page to a partner. Your partner should be able to point through this chain:

user need -> input -> process -> output

Exit sentence: "My gadget receives ____, processes it by ____, and ____ so the user can ____."

Word bank: detects · measures · receives · compares · warns · displays · moves · opens · guides · sends

Aprende: sigue la información

Un sistema inteligente tiene una entrada, un proceso y una salida. El proceso es la regla que sigue el gadget.

  • La entrada es la información o señal que recibe el gadget.
  • El proceso es lo que el gadget hace con la entrada. Muchas veces sigue una regla si-entonces.
  • La salida es la acción, el sonido, la luz, el movimiento o el mensaje que produce el gadget.

Ejemplo: Un secador de manos automático detecta las manos cercanas. Si detecta manos, se enciende. El aire caliente es la salida.

Palabras de hoy: necesidad del usuario · sensor · entrada · proceso · salida

Escoge la necesidad antes del gadget

Regresa a la Página 1. ¿Qué problema le importa a tu héroe? Escoge una persona o grupo afectado por ese problema. Tu gadget debe ayudarle a hacer algo que ahora no puede hacer fácilmente.

Oración para planear: "Mi usuario necesita una manera de ____ cuando ____."

Crea la Página 2

Incluye:

  • el nombre del gadget;
  • la necesidad del usuario o el problema;
  • un dibujo con etiquetas;
  • por lo menos una entrada;
  • un proceso, incluyendo una regla si-entonces cuando corresponda; y
  • por lo menos una salida.
Si te atoras: Comienza con la señal. ¿Qué podría detectar o recibir el gadget: luz, sonido, movimiento, distancia, temperatura, un botón o un mensaje? Después decide qué debe pasar.

Sigue la cadena

Muéstrale la página a un compañero. Tu compañero debe poder señalar esta cadena:

necesidad del usuario -> entrada -> proceso -> salida

Oración de salida: "Mi gadget recibe ____, lo procesa al ____ y ____ para que el usuario pueda ____."
