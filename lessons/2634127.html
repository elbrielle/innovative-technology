PERMISSION TO COME ABOARD

HorizonBot will not move until you write the steps.

📅 Intro to AI · Lesson 2
🛠️ Pseudocode + The Docks
⏱️ ~45 min
📦 An algorithm for 4 boxes
  • English
  • Español

📢 HorizonBot is parked on the dock. Four heavy boxes are scattered across The Docks, and the New Horizon is waiting at the pier. The robot will not move one inch until somebody writes down exactly what to do — step by step. Today that somebody is you.

Today's words

algorithm • pseudocode • computer program • loop • conditional

1

Learn what an algorithm is

Complete the EdPuzzle: Permission to Come Aboard with Algorithms and answer the questions inside the video. You need this before you write anything.

2

See how a plan turns into code

Pseudocode is how programmers pre-write an algorithm: plain language a human can read, but that a computer cannot run yet. Here is the same maze solved three ways — first the plan, then two versions a computer can actually execute.

Pseudocode

Start
Go Forward
Turn Left
Go Forward
Turn Right
Go Forward
End

Blockly

move forward
turn left ↺
move forward
turn right ↻
move forward

JavaScript

moveForward();
turnLeft();
moveForward();
turnRight();
moveForward();

Same steps every time. Only the language changes.

3

Read the map of The Docks

Before you write anything, study the map. Find these four things:

• HorizonBot — the blue robot, on the left side of the dock

• The four boxes — the orange crates scattered across The Docks

• The obstacles — the dark red crates already stacked on the dock floor

• The New Horizon — the ship at the pier on the right, over the water

Ask yourself: how will you get HorizonBot to every box and then to the ship? Is there more than one way to do it?

4

Write your pseudocode algorithm

Your goal: move HorizonBot from its starting spot, through The Docks, pick up all four boxes, and deliver them to the New Horizon. Write your algorithm using only these pseudocode terms:

Start  •  Move Forward  •  Turn Right  •  Turn Left  •  End

Write one instruction per line, in order, from Start to End.

📖 KEY VOCABULARY

• Algorithm — a set of steps to complete a specific task

• Computer program — a series of instructions or a plan, usually followed in sequence, but it can also include loops and questions called conditionals

• Loop — a set of instructions that repeats. In Scratch this is usually a 'Forever' or 'Repeat Until' block

• Conditional — a set of instructions that runs only if a certain condition is met. In Scratch, 'Repeat Until' is a loop that keeps repeating the code inside it until the condition is met — in this lesson, until the robot touches the color of the boxes on the dock

• Pseudocode — a prewriting step done before you write a program, in natural, easy-to-read language with no formatting, to explain what you want the code to do. Pseudocode cannot be run by a computer as a working program

🔍 OPTIONAL CHALLENGE: MAKE IT MORE EFFICIENT

Your first algorithm will work. Now make it better.

• Read your algorithm out loud to a teammate while they trace it on the map. Does the robot end up where you said it would?

• Make it more efficient: combine steps, delete steps you do not need, or change the order

• Invent your own pseudocode term to shorten it — Pick Up Box, Hold Box, Move Diagonal, anything that saves you lines

Fewer instructions that still finish the job = a better algorithm.

Aprende qué es un algoritmo

Completa el EdPuzzle: Permission to Come Aboard with Algorithms y contesta las preguntas dentro del video. Lo necesitas antes de escribir nada.

2

Mira cómo un plan se convierte en código

El pseudocódigo es como los programadores planean un algoritmo antes de programarlo: lenguaje normal que una persona entiende, pero que una computadora todavía no puede ejecutar. Aquí está el mismo laberinto resuelto de tres formas: primero el plan y luego dos versiones que la computadora sí puede ejecutar.

Pseudocode (pseudocódigo)

Start
Go Forward
Turn Left
Go Forward
Turn Right
Go Forward
End

Blockly

move forward
turn left ↺
move forward
turn right ↻
move forward

JavaScript

moveForward();
turnLeft();
moveForward();
turnRight();
moveForward();

Los mismos pasos siempre. Lo único que cambia es el lenguaje.

3

Lee el mapa de The Docks

Antes de escribir nada, estudia el mapa. Busca estas cuatro cosas:

• HorizonBot — el robot azul, del lado izquierdo del muelle

• Las cuatro cajas — las cajas naranjas repartidas por The Docks

• Los obstáculos — las cajas rojo oscuro que ya están apiladas en el piso del muelle

• El New Horizon — el barco en el embarcadero de la derecha, sobre el agua

Pregúntate: ¿cómo vas a llevar a HorizonBot a cada caja y luego al barco? ¿Hay más de una forma de hacerlo?

4

Escribe tu algoritmo en pseudocódigo

Tu meta: mover a HorizonBot desde donde empieza, cruzar The Docks, recoger las cuatro cajas y entregarlas al New Horizon. Escribe tu algoritmo usando solo estos términos de pseudocódigo:

Start  •  Move Forward  •  Turn Right  •  Turn Left  •  End

Escribe una instrucción por línea, en orden, desde Start hasta End.

📖 VOCABULARIO CLAVE

• Algoritmo — un conjunto de pasos para completar una tarea específica

• Programa de computadora — una serie de instrucciones o un plan que generalmente se sigue en secuencia, pero que también puede incluir bucles y preguntas llamadas condicionales

• Bucle — en un programa de computadora, un conjunto de instrucciones que se repiten o hacen un bucle. En Scratch esto se logra generalmente con un bloque de "Por Siempre" o "Repetir Hasta"

• Condicional — un conjunto de instrucciones que se ejecuta si se cumple una cierta condición. En Scratch, el "Repetir Hasta" es un bucle que continúa repitiendo el código dentro de su segmento hasta que se cumple la condición establecida; en el ejemplo de esta lección, el código se repite hasta que el robot toca el color de las cajas en el muelle

• Pseudocódigo — actividad de preescritura que se hace antes de escribir un programa, redactada en un lenguaje natural y fácil de entender, sin formato, para explicar el comportamiento deseado del código. Las instrucciones en pseudocódigo no pueden ser ejecutadas por una computadora como un programa funcional
