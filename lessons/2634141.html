MACHINE LEARNING RELIABILITY LAB · DAY 3 OF 5

Audit Representation

Sort the evidence and name the missing proof.

  • Tool: saved Picture This model or class model + case file
  • Time: one class period
  • Turn in: Case File page 4: representation audit

Model Reliability Case File

Use the same case file all week. Choose the format that works best for you.

Download PDFDownload editable Word copy · Make a Google copy

Today’s task

  1. Review the Day 2 results by condition.
  2. Sort conditions into well represented, weak evidence, or not tested.
  3. Identify one evidence gap.
  4. Name the exact examples you would add or test.
  5. Explain why that repair targets the gap.

Case File checkpoint

Complete page 4. Keep every page together for the final decision on Day 5.

Success criteria

  • ✓ Evidence supports each category
  • ✓ Untested is not labeled as failed
  • ✓ The repair is specific
  • ✓ The repair matches the gap
Use this sentence stem:
The model has weak evidence for _____. We would add/test _____ because _____.

Word bank: represented · underrepresented · untested · rebalance · targeted repair

Before you submit

  • Upload a readable copy of today’s completed case-file page. You may upload a document, PDF, photo, or short video walkthrough.
  • Keep your full case file for Day 5.
