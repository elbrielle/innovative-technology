TEXT CODE · DAY 1 / CÓDIGO DE TEXTO · DÍA 1

Lesson 3: Text Code — Trace, Predict + Repair

Topic / Tema: Trace and repair text code / Seguir y reparar código de texto

I can: I can trace nested loops, predict the full output, and use evidence to repair one boundary error.

Puedo: Puedo seguir bucles anidados, predecir el resultado completo y usar evidencia para reparar un error de límite.

Show Your Learning / Demuestra lo aprendido

Passport 5 trace/repair record, prediction made before Run, before/after simulator evidence, corrected JavaScript, and a row/column explanation.

Registro de seguimiento/reparación del Pasaporte 5, predicción antes de Ejecutar, evidencia del simulador antes/después, JavaScript corregido y explicación de filas/columnas.

Tools / Herramientas

Open MakeCode Arcade · Day 1 highlighted bug route

  • English: Make a Google copy · Word · PDF
  • Español: Crear una copia de Google · Word · PDF

Now / Ahora

English

  1. Open a new MakeCode Arcade project, select JavaScript, and paste the Bug Challenge code.
  2. Before Run, use Passport 5 to label the supplied string, number, and Boolean variables and the operations you notice.
  3. Trace one complete row. Record how many placements happen in one inner-loop pass and predict the full 3 × 4 total.

Español

  1. Abre un proyecto nuevo de MakeCode Arcade, selecciona JavaScript y pega el código Bug Challenge.
  2. Antes de Ejecutar, usa el Pasaporte 5 para identificar las variables de texto, número y Booleano proporcionadas y las operaciones que observas.
  3. Sigue una fila completa. Registra cuántas colocaciones ocurren en una pasada del bucle interior y predice el total de 3 × 4.

Next / Después

English

  1. Run once and capture the unexpected grid and score before changing code.
  2. Find the loop condition that does not match its counter. Change only that boundary, run again, and capture the repaired result.
  3. Explain how the outer loop handles rows and the inner loop handles columns. The code you identify helps you trace; the one-line repair you make is what you submit for credit.

Español

  1. Ejecuta una vez y captura la cuadrícula y puntuación inesperadas antes de cambiar el código.
  2. Encuentra la condición del bucle que no coincide con su contador. Cambia solamente ese límite, ejecuta otra vez y captura el resultado reparado.
  3. Explica cómo el bucle exterior controla las filas y el interior las columnas. El código que identificas te ayuda a seguir el programa; la reparación de una línea que haces es lo que entregas para recibir crédito.

Done / Al terminar

Submit Passport 5, the before/after evidence, readable corrected code, and the explanation.

Entrega el Pasaporte 5, la evidencia antes/después, el código corregido legible y la explicación.

Points / Puntos: 25 points: trace/types/operations 5; prediction 5; before/after evidence 5; exact repair 5; explanation 5.
25 puntos: seguimiento/tipos/operaciones 5; predicción 5; evidencia antes/después 5; reparación exacta 5; explicación 5.

Privacy / Privacidad: Use a class-safe project name. Crop names, email addresses, and profile details from screenshots. Do not submit a public share link. / Usa un nombre seguro para el proyecto. Recorta nombres, correos y datos del perfil. No entregues un enlace público.
