TEACHER ONLY · LESSON GUIDE

Picture This Day 2 — Data Makes the Model

Use this page to run the lesson. The student item directly below remains the independent and absence route.

Daily Learning Contract

Topic: Training data and bias

Objective: Students will explain collect → train → test and identify how missing variety can make a model unfair or unreliable.

TEKS:

  • §126.19(c)(6) — The student uses digital tools to transform data, make inferences, and predictions. The student is expected to use digital tools in order to transform data, analyze trends, and predict possibilities and develop steps for the creation of an innovative process or product.

Demonstration of learning: Annotated three-page packet and five written responses.

Before class

Time: One class period

Student route:
Day 2 · Data Makes the Model

Use what already exists: Picture This Day 2 student packet DOCX/PDF; projected current student page.

Lesson flow

  1. Launch: Revisit a failure from yesterday's model.
  2. Model: Model annotating one collect/train/test claim in the packet.
  3. Do: Students read and annotate the packet independently or with a partner.
  4. Check + support: Use an annotation checkpoint and a word bank for data, pattern, variety, and bias; offer audio/partner reading.
  5. Close + handoff: Collect the responses and preview tomorrow's hand-sorting test.

Check before students leave

Ask each student or team to point to the specific evidence named above and explain one choice, test, or revision. Completion alone is not evidence of understanding.

Support + troubleshooting

Scaffold: Keep the visual task sequence visible, assign purposeful partner roles, and use the sentence stems on the student page before simplifying the task.

When stuck: Ask students to show the exact step where the system stopped, then check setup, inputs, and saved work before replacing the task.
