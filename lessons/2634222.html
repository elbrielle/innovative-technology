Facilitator's Guide and Materials: Lesson 1 Wiring LEDs with micro:bit Expansion Board

Run the lesson here; the student item below remains the independent and absence route.

Daily Learning Contract

Topic: Circuit outputs
Objective: Students will wire LED modules and program a functioning traffic light.
Demonstration of learning: Traffic-light worksheet, working build, and checkpoint.

TEKS:

  • §126.19(c)(12)(F) — apply appropriate troubleshooting techniques and seek technical assistance as needed;
  • §126.19(c)(1)(E) — develop, compare, and improve algorithms for a specific task to solve a problem; and

Before class

Time: One class period
Student route: Learn: Lesson 1 Wiring LEDs with micro:bit Expansion Board
Use what already exists: Keep existing guide/presentation/RISE/checkpoint. Use the Kitronik student worksheet; the first current worksheet link opens the teacher guide and needs correction.

Lesson flow

  1. Launch: Launch with a concrete question or failure that makes circuit outputs matter.
  2. Model: Model one current example or tool move before students begin.
  3. Do: Guide the first decision together, then release students to the existing Canvas task.
  4. Check + support: Check for the named evidence, not completion alone; keep a visual sequence, sentence stems, and purposeful partner roles available.
  5. Close + handoff: Collect or verify the evidence and name the next lesson's connection.

Check before students leave

Ask students to point to the specific evidence above and explain one choice, test, or revision. Completion alone is not evidence of understanding.

Support + troubleshooting

Scaffold: Keep the visual task sequence visible, assign purposeful partner roles, and use the sentence stems on the student page before simplifying the task.

When students get stuck: Ask for the exact step where the tool, code, or task stopped. Check setup, inputs, and saved work before replacing the task or lowering the thinking.

Students seat the micro:bit in the expansion board, wire the LED modules, and program a working traffic light. This is the first lesson where wiring mistakes, not code mistakes, are what stops them — budget time for checking connections.
