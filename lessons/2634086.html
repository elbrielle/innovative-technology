Lab 1: Complete Path + Material Test

Build one dependable lamp circuit, then use it as a test tool instead of changing everything at once.

Day 1: prove the path

  1. Identify battery, switch, lamp, and connecting path.
  2. Build with the switch off. Ask for the battery or insert it only after the circuit matches the diagram.
  3. Close the switch and record what the lamp does.
  4. Open one connection and explain why the output changes.

Day 2: run a fair material test

  1. Keep the same test gap and circuit.
  2. Test four to six dry, teacher-approved materials, one at a time.
  3. Repeat any weak or flickering result before making a claim.
  4. Troubleshoot one incomplete circuit with the power off.
