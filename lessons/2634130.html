DAY 4 · TRAIN + TEST

Train, Test + Improve a Model

A model learns patterns from examples. It does not understand the object.

PAGE 310 POINTS

Topic · objective · success

Topic: Training and testing an image model

Objective: Train two classes, test new examples, and improve the model using evidence.

Success: Two fair classes, three new tests, one evidence-based improvement, and one human-check rule.

Collect → train → test → improve

  1. Choose two objects that are easy to distinguish.
  2. Collect varied training examples for both classes.
  3. Train the image model.
  4. Test three new examples that were not used for training.
  5. Record prediction, confidence, and whether it was correct.
  6. Change the training set based on the evidence.
  7. Name one situation where a human should decide.

Privacy + fairness

Use classroom objects, not faces or personal information. Keep the background and number of examples reasonably fair across both classes.

Confidence is not certainty. A high-confidence prediction can still be wrong.

Turn in · 10 points

Upload Page 3 or submit a clear photo of your test table and improvement.
