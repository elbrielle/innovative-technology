3D MODELING • LESSON 4 TEACHER GUIDE

Favorite Toy: Break a Complex Object into Shapes

Run this after the ring and before Dream Room. The lesson gives students a controlled place to practice shape decomposition before they manage measurement, scale, and room construction at the same time.

Daily Learning Contract

Topic: Shape decomposition and proportional modeling

Objective: Students will analyze a complex object as basic forms and use comparison evidence to revise a proportional 3D model.

TEKS:
  • §126.19(c)(3)(B) — discuss and implement a design process that includes planning, selecting digital tools to develop, test, and evaluate design limitations, and refining a prototype or model; and
  • §126.19(c)(12)(C) — select and use appropriate platform and tools, including selecting and using software or hardware to transfer data;

Demonstration of learning: Toy STL and the existing 2–3 sentence problem-and-solution reflection.

What students learn

Shape decomposition means identifying the smaller forms in an object. Students identify the boxes, cylinders, spheres, tubes, and cutouts inside a familiar toy, then rebuild and revise it in Tinkercad.

8–10 minutes: model large shapes first

Use the headphones example on the assignment. Point to each simple form, then build the largest forms in Tinkercad. Model resize, rotate, Align, Group, and one Hole. Compare the silhouette with the reference before adding detail. Leave the assignment and examples visible while students build.

Two-period teacher flow

  1. Decompose and plan. Model one object with a photo. Trace or name the simple forms before touching Tinkercad.
  2. Build the silhouette. Students block in the largest forms first. Details wait.
  3. Partner check. Can a partner identify the object? Which form looks wrong or is missing?
  4. Revise and submit. Students improve one part, export a STL, and name the change in their reflection.

Canvas setup

Create a Favorite Toy Activity inside your own Tinkercad class and test the student join route before class. The Canvas assignment is a 100-point Major project. Keep Dream Room after it: the two projects assess different skills. If you must cut Favorite Toy, model the decomposition step with one real object before students plan their rooms.

Support during work

Point students to the word bank beside the reflection. Say the tool name, show it, and model the sentence starter aloud. Students may rehearse in Spanish before writing. Keep the same task and submission; these supports are not extra assignments.

Model the submission: select the complete design, choose Export and .STL, open Downloads, and name the file LastName-FirstName-toy.stl. Upload it to the existing assignment and keep the current reflection. Keep the editable design available in Tinkercad. STL contains geometry, not color; inspect the editable model for color and modeling choices.
