Series test

  1. Predict what happens if one lamp is removed.
  2. Build two lamps in one path.
  3. Record brightness and remove one lamp.
  4. Trace where the only path breaks.

Parallel test

  1. Find the branch and return points on the diagram.
  2. Build the same two lamps on separate branches.
  3. Remove one lamp and record what the other does.
  4. Compare the result to the series test.

Reliability challenge

Build or diagram a two-light system where one lamp can be removed while the other stays on. A partner must trace the route and run the failure test.
