DAY 3 · LEARN

How Does Floor Color Change a Decision?

The RVR is not guessing. A sensor measures color and the program decides what happens next.

TOPIC

Color sensing

OBJECTIVE

Students will explain how a floor color becomes an input that changes program behavior.

DEMONSTRATION OF LEARNING

Students will identify the input, decision, and output in a color-sensor program.

System model

Input: the downward-facing sensor reads a floor color.

Decision: the program checks which color was detected.

Output: the robot changes light, sound, speed, direction, or stop behavior.

Exit check
