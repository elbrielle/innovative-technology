Materials + prep

  • A class set of micro:bits with battery packs and USB cables, tested. Lessons 2 and 3 both download code to the device; a micro:bit with a dead battery reads as broken code to a student.
  • Microsoft accounts working at arcade.makecode.com, checked on a student device before Lesson 4. Not Google, not Clever — the page says so and it is the single most common failure in this unit.
  • EdPuzzle class code tested, for Lesson 1.
  • Partners assigned for the Lesson 1 interviews. This is a talking lesson before it is a building lesson, and it sets up the whole unit.
  • Each Google Assignments worksheet opened once by you, so you know the hand-back path works. The student copy generates when they launch the item from Canvas.

Watch-fors

  • Sign in first, or Lesson 5 has nothing to open. Lesson 5 starts by opening the Lesson 4 game from My Projects. If a student built Lesson 4 signed out, that project is gone and they start over. On shared laptops, have them sign in with Remember Me turned off so the next class does not land in their account.
  • The four “Learn:” items launch an interactive lesson in a new tab and show a blank page in Canvas. Nothing is broken. Tell students once, at Lesson 1.
  • Activity: Seasick with Empathy now collects a written response in Canvas — students type the empathy map and problem statement into the submission box. It is a 5-point Minor grade, so the empathy map that opens the unit does reach the gradebook.
  • The micro:bit lessons lean on earlier units and say so. Lesson 2 refers back to Coding Adventures for inputs and outputs, Lesson 3 to the micro:bit games lesson, Lesson 4 to Video Game Design for the Arcade workflow. If a student did not take those, the lesson still stands alone — but the confidence gap is real, so pair them up.
  • Two items are currently unpublished — Learn: Lesson 1 Seasick with Empathy and the Lesson 4 heading. Publish them when you set the unit live, or Lesson 1 opens with a video students cannot reach and Lesson 4 arrives without its heading.

Grading

Five items carry points, all Minor grades at 5 points each — 25 total: Activity: Seasick with Empathy, Do: micro:bit Light Meter, Do: Crab Cruisin’, Do: Ocean Games and Lesson 5: AI Enemies. There is no Major grade in this module. Every “Learn:” launch and the EdPuzzle are set to 0. The four Do lessons submit their worksheets through Google Assignments; the Activity is typed into Canvas.
