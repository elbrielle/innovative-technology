GRAPHIC DESIGN WITH CANVA

Visual Communication Using Shape Constraints

3. Answer the reflection questions:

Q1: What did you try to show in your lines-only design?

"I chose the word ______. I used lines to show this by ______."

Q2: How did using only circles change your design compared to using lines?

"Using circles was ______ because ______."

WORD BANK:

For Q1: spacing • direction • thickness • overlapping • repeating • angles • curves

For Q2: easier • harder • different • similar • limiting • creative • challenging • fun

WORD BANK / BANCO DE PALABRAS:

Q1: spacing (espacio) • direction (dirección) • thickness (grosor) • overlapping (superposición) • repeating (repetición) • angles (ángulos) • curves (curvas)

Q2: easier (más fácil) • harder (más difícil) • different (diferente) • similar (parecido) • limiting (limitante) • creative (creativo) • challenging (desafiante) • fun (divertido)
