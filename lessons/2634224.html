Wire the LEDs and build a traffic light

2

Wire the LED modules

Seat the micro:bit in the expansion board, then connect each LED module to the pin the worksheet names.

Check every connection before you plug in power.

3

Program the traffic light

Code the red, yellow, and green lights to run in the right order.

Set the timing so a driver would actually have time to react to each change.

⚡ Cut the power before you rewire

Unplug the battery or the USB cable before you move a module. Rewiring a live board is the fastest way to kill a component.

If a light never comes on, check the pin number on the board against the pin number in your code. They disagree more often than the wire is bad.
