Intro to CS · Day 1 of 10

Your First Code

Build a sequence, run it, and use the result to revise your instructions.

  • Tool: Code.org Express, Lesson 1
  • Time: one class period
  • Turn in: progress screenshot and reflection
  • English
  • Español

English

Words for today: algorithm · program · sequence

What to do

  1. Sign in through your teacher's Code.org section so your progress saves. Open Programming with Angry Birds.
  2. Before moving a block, say the route in ordinary words. That ordered plan is the algorithm.
  3. Build the plan with blocks and run it. If the result is wrong, change one block and run it again.
  4. At the end of class, capture the lesson progress screen with your completed levels visible.

If your code is not working

  1. Read the instruction at the top of the level again.
  2. Run the code after one change so you know which change mattered.
  3. Use the built-in hint, then show your teacher the level and what you already tried.

Before you submit

  • Upload a readable progress screenshot.
  • In the submission comment, complete the reflection below.

Reflection

Write 2 or 3 sentences: "The computer did something I did not expect when I ____. I figured out it was because ____."

Word bank: algorithm · program · sequence · block · order · run

Español

Palabras de hoy: algorithm (algoritmo) · program (programa) · sequence (secuencia)

Qué hacer

  1. Inicia sesión en la sección de Code.org de tu maestro para guardar tu avance. Abre Programming with Angry Birds.
  2. Antes de mover un bloque, di la ruta con palabras comunes. Ese plan ordenado es el algoritmo.
  3. Construye el plan con bloques y ejecútalo. Si el resultado no funciona, cambia un bloque y vuelve a ejecutarlo.
  4. Al final de la clase, toma una captura de la pantalla de avance con tus niveles completados visibles.

Si tu código no funciona

  1. Vuelve a leer la instrucción que aparece arriba del nivel.
  2. Ejecuta el código después de un solo cambio para saber cuál cambio importó.
  3. Usa la pista del nivel. Después, muéstrale a tu maestro el nivel y lo que ya intentaste.

Antes de entregar

  • Sube una captura legible de tu avance.
  • En el comentario de la entrega, completa la reflexión de abajo.

Reflexión

Escribe 2 o 3 oraciones: "La computadora hizo algo que no esperaba cuando ____. Descubrí que fue porque ____."

Banco de palabras: algoritmo · programa · secuencia · bloque · orden · ejecutar
