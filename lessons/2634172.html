DAY 3 · DO

Color Sensor Mission

Build the route, collect actual results, and show how the sensor changes the robot's behavior.

TOPIC

Color-sensor control

OBJECTIVE

Students will build and debug the green-to-red Sphero route.

DEMONSTRATION OF LEARNING

Students will submit route evidence, code evidence, test results, and a systems explanation.

Core steps

  • Build a green-to-red route with the cards about 18 to 24 inches apart.
  • Use roll and delay blocks to stop on each color.
  • Add a one-second start delay.
  • Place the total color sensor block inside a main LED block after each stop.
  • Test, record the expected and actual LED color, and revise the route or code.

Optional extension

Continue the official Sphero lesson to add color events, a red stop sequence, direction controls, or a color-boundary challenge.

Turn in

  • Screenshot of final code
