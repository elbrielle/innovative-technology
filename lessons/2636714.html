Branching Narratives · Lessons 4–6

Students first make a small choice-and-outcome prototype, then plan and build a Halloween escape room with clue-based questions. Scenario Builder is the default. No superhero or visitor theme is required.

Before class

  1. Use the existing ThingLink button and class sign-in route. Check Scenarios and sharing on the student license before Lesson 4.
  2. Open a blank scenario. Rehearse Text, Media, Simple branching, connections, Preview, and Share link. Check the scenario and the media inside it with the intended audience.
  3. Choose one teaching route: a short section of the tutorial with pauses, or the live demo below. Do not run both in full.
  4. Open the slide deck and Canvas English/Español tabs. Students who miss class can follow the illustrated steps on the assignment.

Keep the practice small: one start scene, one Simple branching block, two outcome scenes. Text or existing media is enough. This prepares students to route answers in the escape room.

Live demo checklist

  1. Scenarios → Create scenario → name → Create → Create blank scenario.
  2. New block → Text: write a short start scene. Connect the start point to it.
  3. New block → Branching → Simple branching: add the question and two choice labels; save. Connect the start scene to this block.
  4. Add two Text outcome scenes. Drag each branching output circle to the matching outcome.
  5. Preview from the start. Test both choices. Deliberately change one connection and show how to repair it.
  6. For Lesson 6, add Media → Upload or select a scene, select a 360 scene, and connect it as part of the route.
  7. Share → Share link → Copy. Test with the intended audience, then demonstrate Canvas Website URL submission and the existing comment box.

Lesson 5. Plan the Halloween escape room · about 50 minutes

5 min: introduce a Halloween setting and escape goal. 8 min: trace the complete museum example below, including correct and incorrect answers. 5 min: inspect the actual handwritten map. 24 min: plan and confer. 8 min: photograph, submit, review.

Your Halloween escape room:

  • 4+ story scenes, including a start and two endings: escape / do not escape.
  • 2+ decision points with questions or puzzles. Each answer leads to a consequence.
  • 1 scene in 360° that is part of the route.

Branching blocks connect the scenes; they do not count as extra story scenes.

Small example: escape the haunted museum

  1. Entrance: the clue says “use the even-numbered key.” Choose 4 → gallery. Choose 3 → alarm.
  2. Gallery (360°): the clock reads 3:00. Choose code 0300 → exit. Choose 3000 → alarm.
  3. Exit: you escaped.
  4. Alarm: you did not escape. Restart to try again.

Escape route: Entrance → Gallery → Exit. Other ending: Entrance → Alarm. Put both clues in the scenes so players can solve them.

On the existing map, students show the clue, question, correct answer and incorrect-answer destination. The two clue-based questions can be the two required decision points. This is part of the escape-room project, not a separate quiz assignment or extra artifact. Story scenes count; Branching control blocks do not.

Approve through the existing Canvas comment or conference. While waiting, students improve clues or gather media. Do not add an approval worksheet.

Lesson 6. Build and test the Halloween escape room · about three periods

Build 1: 5 min retrieve plans, 8 min Media/clue demo, 32 min build, 5 min save. Build 2: 5 min route check, 40 min build/accessibility, 5 min save. Test/submit: 5 min feedback model, 15 min partner playtest, 20 min improve/retest, 10 min submit.

Use Simple branching to connect answer choices to scenes. A correct answer can unlock the next scene; an incorrect answer can lead to a hint, retry route, or non-escape ending. Ensure the finished project still has two distinct endings. Test correct AND incorrect answers, the 360 scene, and access to the scenario and its media.

Keep the existing 100-point rubric and two submission-comment questions. The clue/answer work fits plan and story structure, choice and consequence, and navigation; do not create a sixth grading category.

Optional Question block: only if you teach it

Simple branching is enough for the required question routes. For a Question block, use New block → Question → Multiple-choice, add answers and mark the correct one. Add a Wrong answer message to require a retry. Without that message, an incorrect answer can continue. Answer options shuffle, so clues should name answers rather than positions. Preview both correct and incorrect responses. A Question block alone is not a second story ending.

If Scenario Builder cannot share

K–12 scenario sharing depends on the license. Check current sharing requirements. Choose the fallback for the whole affected class before building, and tell students which route applies. Do not ask students to upgrade or make work public.

Teacher-selected fallback: use regular ThingLink scenes connected with Transit / Create tour tags. Demonstrate the current tag picker in your account. Keep the same story map, decisions, outcomes, 360 scene, testing and rubric. Two-Door uses three scenes; the final uses at least four. Submit only the starting scene’s share link.

  1. Create the story scenes first. Open the start scene and click Edit.
  2. Add a tag and choose the tour/transition option (often called Create tour). Select the destination scene and give the choice a clear title.
  3. Add the second choice and connect its destination. Repeat at the second decision for the final project.
  4. Preview every route. Check all destination scenes for the intended audience. Share the starting scene URL.

If the school disables all student sharing, use an in-class teacher review of the student’s preview plus the existing reflection. Set a class-specific Canvas submission accommodation before class; do not silently require a file in a Website URL-only assignment.

Access and recovery

  • EN/ES tabs contain the same task and submission requirements. The original video is in English; the Spanish illustrated steps provide the build route.
  • Word banks and sentence stems are beside the work. Let students rehearse orally before writing their existing comments.
  • Absent or stuck: reopen the Canvas screenshots, use text blocks first, and rebuild only the missing connection. Confident students can refine consequences without adding more required scenes.
  • If a link opens for its creator but not a partner, check both the scenario audience and each media scene. Public access is not required.
