MACHINE LEARNING RELIABILITY LAB · DAY 2 OF 5

Stress-Test the Model

Run the plan and find a repeated failure pattern.

  • Tool: saved Picture This model or class model + case file
  • Time: one class period
  • Turn in: Case File page 3: stress-test log + evidence claim

Model Reliability Case File

Use the same case file all week. Choose the format that works best for you.

Download PDFDownload editable Word copy

Today’s task

  1. Predict before each test.
  2. Run all 12 planned tests.
  3. Record the actual label, predicted label, confidence score, and changed condition.
  4. Tally correct, incorrect, and uncertain results.
  5. Write one claim supported by a count.

Case File checkpoint

Complete page 3. Keep every page together for the final decision on Day 5.

Success criteria

  • ✓ All 12 rows are complete
  • ✓ Actual and predicted labels are both shown
  • ✓ Confidence is recorded
  • ✓ The claim names a condition and count
Use this sentence stem:
The model was least reliable when _____. In _____ of _____ tests, it _____.

Word bank: prediction · confidence · correct · incorrect · uncertain · incident · pattern

Before you submit

  • Upload a readable copy of today’s completed case-file page. You may upload a document, PDF, photo, or short video walkthrough.
  • Keep your full case file for Day 5.
