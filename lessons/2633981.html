How to use this map

Use Modules as the course table of contents. The order below matches the live course. Publish only the current student work and keep Facilitator's Guides unpublished.

Intentional SW1 change

Piskel Micro Animation stays between Comics and Graphic Design. Its superhero theme makes it a useful bridge from comic storytelling into visual-design work. Its current module title still labels it Enrichment, so teachers should decide whether to use it before the graphic-design unit.

Before publishing a six weeks

  • Read each Facilitator's Guide and check the source links.
  • Confirm apps, accounts, hardware, and consumable supplies.
  • Set your own due dates and remove items you will not teach.
  • Check the module in Student View from top to bottom.
