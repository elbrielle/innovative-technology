DAY 1 · DO

Drawing Mission: Plan, Program, Prove

Code leaves a visible trace. Your evidence should show what changed between the first and final run.

TOPIC

Robot drawing

OBJECTIVE

Students will plan, program, test, and revise a recognizable robot drawing.

DEMONSTRATION OF LEARNING

Students will submit a completed mission sheet plus photo or screenshot evidence of the drawing and program.

Mission

  • Choose a simple word or symbol with short lines, turns, and curves.
  • Sketch a robot-friendly plan before building the program.
  • Connect to the correct RVR and record its robot ID.
  • Run the drawing, capture the result, and make one code revision.
  • Run it again and explain what improved.

Mission sheet

Use the editable Word file or print the PDF.

Download Word mission sheet · Make a Google copy Download PDF mission sheet

Turn in

  • Completed mission sheet
  • Photo or screenshot of the final drawing
  • Screenshot of the program
  • One sentence naming the hardest move and the revision that helped

PASSPORT 7 / PASAPORTE 7

Plan and revise a robot drawing as a team / Planear y revisar un dibujo del robot en equipo

I can: I can compare solutions, document a team algorithm and timeline, and revise it after the robot follows it literally.

Puedo: Puedo comparar soluciones, documentar un algoritmo y cronograma del equipo y revisarlo después de que el robot lo siga literalmente.

Show Your Learning / Demuestra lo aprendido

Complete Passport Checkpoint 7 with the team problem, two possible solutions, selection, roles, timeline, and pseudocode. Use the existing mission sheet for the drawing sketch, robot ID, first/final run, revision, and reflection. Submit both without duplicating answers.

Completa el Punto de control 7 con el problema del equipo, dos soluciones posibles, la selección, roles, cronograma y pseudocódigo. Usa la hoja de misión existente para el boceto, ID del robot, primera/última prueba, revisión y reflexión. Entrega ambos sin duplicar respuestas.

  1. Now / Ahora: Use Passport 7 for the problem, two possible solutions, selected plan, roles, timeline, and pseudocode.
    Usa el Pasaporte 7 para el problema, dos soluciones posibles, el plan elegido, los roles, el cronograma y el pseudocódigo.
  2. Next / Después: Use the mission sheet for the drawing sketch, robot ID, first/final run evidence, revision, and reflection. Keep Passport 7 as the team planning record.
    Usa la hoja de misión para el boceto, ID del robot, evidencia de la primera y última prueba, revisión y reflexión. Conserva el Pasaporte 7 como registro de planificación del equipo.
  3. Done / Al terminar: Submit both files without copying the same response twice, then complete the transfer reflection.
    Entrega ambos archivos sin copiar la misma respuesta dos veces y completa la reflexión de transferencia.
