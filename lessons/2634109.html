Intro to CS · Day 5 of 10

Explore Websites and Start HTML

Look behind a web page, then write the tags that give a page its structure.

  • Tool: CS Discoveries Unit 2, Lessons 1 and 2
  • Time: one class period
  • Turn in: first HTML page screenshot and reflection
  • English
  • Español

English

Words for today: HTML · tag · element

What to do

  1. Open Exploring Web Pages. Complete the assigned levels and notice how the code connects to what appears in the preview.
  2. Open Intro to HTML. Complete the assigned levels.
  3. In Web Lab, write a heading and a paragraph. Change one piece of text and run the page again so you can see which code controls it.
  4. Capture the code and the preview together. The screenshot should make both readable.

If your code is not working

  1. Check that each opening tag has the closing tag the lesson expects.
  2. Look for a missing angle bracket if code appears as ordinary text on the page.
  3. Change one line at a time, then compare the preview.

Before you submit

  • Upload one screenshot showing your HTML and its page preview.
  • In the submission comment, complete the reflection.

Reflection

Write 2 or 3 sentences: "The ____ tag controls ____. I know because when I changed ____, the page ____."

Word bank: HTML · tag · element · heading · paragraph · preview

Español

Palabras de hoy: HTML · tag (etiqueta) · element (elemento)

Qué hacer

  1. Abre Exploring Web Pages. Completa los niveles asignados y observa cómo el código se conecta con lo que aparece en la vista previa.
  2. Abre Intro to HTML. Completa los niveles asignados.
  3. En Web Lab, escribe un encabezado y un párrafo. Cambia una parte del texto y vuelve a ejecutar la página para ver qué código la controla.
  4. Toma una captura del código y la vista previa juntos. Los dos deben poder leerse.

Si tu código no funciona

  1. Revisa que cada etiqueta de apertura tenga la etiqueta de cierre que pide la lección.
  2. Busca un signo de menor o mayor que falte si el código aparece como texto común en la página.
  3. Cambia una línea a la vez y compara la vista previa.

Antes de entregar

  • Sube una captura que muestre tu HTML y la vista previa de la página.
  • En el comentario, completa la reflexión.

Reflexión

Escribe 2 o 3 oraciones: "La etiqueta ____ controla ____. Lo sé porque cuando cambié ____, la página ____."

Banco de palabras: HTML · etiqueta · elemento · encabezado · párrafo · vista previa
