Stop Motion Lesson 0 — Process Video and Setup

Daily Learning Contract

Topic: Stop-motion production workflow

Objective: Students will explain the planning, filming, and editing sequence used to produce a readable stop-motion film.

TEKS: No independent Grade 8 Technology Applications TEKS claim. This lesson provides operational, preparatory, or cross-curricular evidence.

Demonstration of learning: Completed 10-question EdPuzzle and one filming-quality takeaway connecting the video to the upcoming project.

Before class

  • Reconnect the external-tool EdPuzzle, select the reusable video, set captions/skipping, and test it in Student View.
  • Remove the teacher-only setup box from the student assignment before the route is published.
  • Keep the original video and question list ready as a fallback.

Five-part lesson flow

  1. Launch: State the production question students should answer while watching.
  2. Teacher setup: Confirm the external-tool assignment actually opens for a student before releasing it.
  3. Watch and respond: Students complete the 10 questions with captions and rewind available.
  4. Debrief: Map the video process to plan, plot, storyboard, film, and final edit.
  5. Evidence: Verify EdPuzzle completion and collect one filming-quality takeaway.

Check before students leave

Every assigned student can access the player or the documented fallback and has completed the response activity.

Support without lowering the thinking

Turn captions on by default and allow replay. Give students a pictured process strip so language load does not hide the production sequence.
