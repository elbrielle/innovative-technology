WEEK 1 · DESIGN THINKING · 5 POINTS

Activity: Ready, Set, Design

Use the worksheet to record how your design changes from the user's need to the test.

  • English
  • Español

Make your copy

  1. Open the Ready, Set, Design worksheet.
  2. Select Make a copy when Google asks.
  3. Answer every prompt in the worksheet. Keep the user and challenge specific enough that another person can follow your thinking.

Turn it in

  1. In Google Docs, choose File > Download > PDF Document.
  2. Return here, select Start Assignment, and upload the PDF.
  3. Open the preview before you submit. Make sure every page is readable.

Word bank: user · need · define · idea · prototype · test · feedback · revise

Sentence stem: After testing, we changed ____ because ____.

Complete work earns 5 points: every worksheet section is answered and the uploaded file is readable.

Haz tu copia

  1. Abre la hoja de trabajo Ready, Set, Design.
  2. Selecciona Make a copy cuando Google te pregunte.
  3. Contesta cada pregunta de la hoja. Describe al usuario y el reto con suficiente detalle para que otra persona pueda seguir tus ideas.

Entrégala

  1. En Google Docs, selecciona File > Download > PDF Document.
  2. Regresa aquí, selecciona Start Assignment y sube el PDF.
  3. Abre la vista previa antes de entregar. Revisa que todas las páginas se puedan leer.

Banco de palabras: usuario · necesidad · definir · idea · prototipo · probar · comentarios · revisar

Oración de apoyo: Después de probar, cambiamos ____ porque ____.

El trabajo completo recibe 5 puntos: cada sección de la hoja está contestada y el archivo se puede leer.
