Intro to CS · Day 2 of 10

Hour of Code

Choose one activity and find the coding ideas inside it.

  • Tool: Hour of Code
  • Time: one class period
  • Turn in: certificate or completion screenshot and reflection
  • English
  • Español

English

Words for today: loop · event · command

What to do

  1. Open the Hour of Code activity list. Choose one activity marked for your grade range.
  2. Try it for five minutes. If the reading level or coding level does not fit, choose a different activity.
  3. Work through the activity on your own screen. Notice one place where order matters, a loop repeats instructions, or an event starts an action.
  4. Capture the certificate, completion screen, or finished project when you reach the end.

If your code is not working

  1. Read the instruction at the top of the level again.
  2. Run the code after one change so you know which change mattered.
  3. Use the built-in hint, then show your teacher the level and what you already tried.

Before you submit

  • Upload a certificate, completion screen, or finished-project screenshot.
  • In the submission comment, name the activity and complete the reflection.

Reflection

Write 2 or 3 sentences: "I chose ____. The hardest part was ____, and I got past it by ____."

Word bank: loop · event · command · repeat · hint · tutorial

Español

Palabras de hoy: loop (bucle) · event (evento) · command (comando)

Qué hacer

  1. Abre la lista de actividades de Hour of Code. Escoge una actividad marcada para tus grados.
  2. Pruébala durante cinco minutos. Si el nivel de lectura o programación no te queda bien, escoge otra actividad.
  3. Trabaja la actividad en tu propia pantalla. Busca un lugar donde el orden importe, un bucle repita instrucciones o un evento inicie una acción.
  4. Toma una captura del certificado, la pantalla de finalización o el proyecto terminado.

Si tu código no funciona

  1. Vuelve a leer la instrucción que aparece arriba del nivel.
  2. Ejecuta el código después de un solo cambio para saber cuál cambio importó.
  3. Usa la pista del nivel. Después, muéstrale a tu maestro el nivel y lo que ya intentaste.

Antes de entregar

  • Sube una captura del certificado, la pantalla de finalización o el proyecto terminado.
  • En el comentario, nombra la actividad y completa la reflexión.

Reflexión

Escribe 2 o 3 oraciones: "Escogí ____. La parte más difícil fue ____, y la resolví al ____."

Banco de palabras: bucle · evento · comando · repetir · pista · tutorial
