Write a reflection for each

In the description box, write 2-3 sentences using these starters:

"In this project, I learned how to..."

"This project shows my skills in..."

EXAMPLE

Band_Logo.png
"In this project, I learned how to combine shapes with the Combo app and blend colors with a gradient to build a 1960s band logo. This project shows my skills in Canva, including compound shapes and color."
