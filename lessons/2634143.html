MACHINE LEARNING RELIABILITY LAB · DAY 5 OF 5

Model Card + Release Decision

Document the evidence, name the limit, and recommend what should happen next.

  • Tool: saved Picture This model or class model + case file
  • Time: one class period
  • Turn in: Complete Model Reliability Case File + 60-second briefing

Model Reliability Case File

Use the same case file all week. Choose the format that works best for you.

Download PDFDownload editable Word copy

Today’s task

  1. Complete the model card on page 6.
  2. Choose approve, revise, restrict, or reject for one named use.
  3. Use at least two findings from the week.
  4. Name one known limit or untested condition.
  5. Write one specific next action.
  6. Prepare a 60-second briefing.

Case File checkpoint

Complete pages 6 and 7. Use the full case file to support the final release decision.

Success criteria

  • ✓ Decision names one intended use
  • ✓ At least two test findings are included
  • ✓ A limit or untested condition is named
  • ✓ The next action is specific
  • ✓ The briefing is ready
Use this sentence stem:
We recommend _____ this model for _____ because our tests showed _____. Before broader use, _____.

Word bank: intended use · limitation · evidence · approve · revise · restrict · reject

Before you submit

  • Submit the complete Model Reliability Case File, including pages 6 and 7. If Canvas accepts one upload, combine photographed pages into one PDF or document.
  • Submit or deliver the 60-second briefing in the format your teacher requests.
