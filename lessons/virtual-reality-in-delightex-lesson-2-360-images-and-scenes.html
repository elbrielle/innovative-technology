Scene 1: Import 360 Photo

⏱️ 25 min

Start with a real 360 photo and bring it into Delightex!

📸 Steps:
  1. Create new project → Select "360 Image"
  2. Choose "Empty Scene"
  3. Download a 360 photo from VR Media Library
  4. In Delightex: Environment → Edit → Upload your image
  5. Add 5+ 3D objects/characters to your scene
  6. Add a door (or any object) to click on
⚠️ Common Mistake: Forgetting to add the door! You need something clickable to switch scenes.
🏗️

Scene 2: Build 3D Version

⏱️ 35 min

Recreate your 360 photo using 3D objects and environments!

🛠️ Steps:
  1. Click "Scenes" → "New Scene" → "3D Environment"
  2. Choose environment that matches your photo (grass, city, etc.)
  3. Change weather to match your photo
  4. Use shapes to create features (lakes, roads, etc.)
  5. Add buildings, characters, objects from your 360 photo
  6. Add another door to switch back to Scene 1
💡 Pro Tip: It doesn't have to be perfect! Just try to capture the main features of your 360 photo.
💻

Code the Door to Switch Scenes

⏱️ 20 min

Make your door clickable using code blocks!

📝 Coding Steps:

For Scene 1 door:

  1. Right-click door → Code icon
  2. Enable "Using code blocks"
  3. Click Code icon → Code Blocks
  4. Events → "When door is clicked"
  5. Control → "Go to scene" → Choose Scene 2

For Scene 2 door:

  1. Repeat steps above
  2. But choose Scene 1 instead
⚠️ Testing: Click Play to test! Door should switch between scenes.

Escena 1: Importar Foto 360

⏱️ 25 min

¡Comienza con una foto 360 real y tráela a Delightex!

📸 Pasos:
  1. Crear nuevo proyecto → Seleccionar "360 Image"
  2. Elegir "Empty Scene"
  3. Descargar foto 360 de la Biblioteca VR
  4. En Delightex: Environment → Edit → Subir tu imagen
  5. Agregar 5+ objetos/personajes 3D a tu escena
  6. Agregar una puerta (o cualquier objeto) para hacer clic
⚠️ Error Común: ¡Olvidar agregar la puerta! Necesitas algo clicable para cambiar escenas.
🏗️

Escena 2: Construir Versión 3D

⏱️ 35 min

¡Recrea tu foto 360 usando objetos y entornos 3D!

🛠️ Pasos:
  1. Clic "Scenes" → "New Scene" → "3D Environment"
  2. Elegir entorno que coincida con tu foto (pasto, ciudad, etc.)
  3. Cambiar clima para coincidir con tu foto
  4. Usar formas para crear características (lagos, caminos, etc.)
  5. Agregar edificios, personajes, objetos de tu foto 360
  6. Agregar otra puerta para volver a Escena 1
💡 Consejo: ¡No tiene que ser perfecto! Solo intenta capturar las características principales de tu foto 360.
💻

Codificar la Puerta para Cambiar Escenas

⏱️ 20 min

¡Haz tu puerta clicable usando bloques de código!

📝 Pasos de Codificación:

Para puerta de Escena 1:

  1. Clic derecho en puerta → Icono Code
  2. Activar "Using code blocks"
  3. Clic icono Code → Code Blocks
  4. Events → "When door is clicked"
  5. Control → "Go to scene" → Elegir Scene 2

Para puerta de Escena 2:

  1. Repetir pasos anteriores
  2. Pero elegir Scene 1 en su lugar
⚠️ Prueba: ¡Haz clic en Play para probar! La puerta debe cambiar entre escenas.
