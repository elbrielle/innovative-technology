Complete Paths + Safe Testing

A circuit works when electricity has a complete path through a load and back to its source.

Objective
Trace and test a complete path
Evidence
Lab 1 + checkpoint
Kit rule
Wire first, power last

Start with the path

Power source→Conductive path→Control→Load/output→Back to source

The switch opens or closes the path. A lamp, LED, motor, or speaker is a load because it uses electrical energy to do a job.

Open or closed?

Open circuitThe path has a break. Current cannot travel around the full loop. The output is off.
Closed circuitThe path is complete. Current can travel through the load and return to the source. The output can turn on.

Five safety moves

  1. Switch off and build before inserting batteries.
  2. Compare the build to the diagram before power.
  3. Never connect the battery terminals directly.
  4. Keep hands, hair, and faces away from a spinning fan.
  5. Disconnect power before changing or returning a circuit.
