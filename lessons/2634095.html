Day 6: LED + resistance

  1. Build the LED circuit with the specified resistor.
  2. Reverse the LED and record the result.
  3. Compare the 100-ohm and 1k resistors with the same LED circuit.
  4. Explain which change affected direction and which affected brightness.

Day 7: motor + status

  1. Build the motor circuit and keep clear of the fan.
  2. Reverse the motor connection and record direction.
  3. Build or diagram a teacher-selected system where a switch controls motion and a light shows system status.
  4. Trace input → path/process → output.
