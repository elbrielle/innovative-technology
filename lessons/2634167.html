DAY 1 · LEARN

Draw Mode or Blocks?

Learn the Sphero EDU workspace before the robot touches the paper.

TOPIC

Robot programming

OBJECTIVE

Students will compare Draw, Blocks, and Text program types and connect to the correct RVR.

DEMONSTRATION OF LEARNING

Students will identify the best program type for a drawing task and explain why.

What to notice

  • Draw mode records a path quickly.
  • Blocks give precise control over heading, speed, duration, lights, and repeated actions.
  • Text is another program type, but this unit starts with Draw and Blocks.
  • A connected robot shows the correct robot ID and battery icon in the Sphero EDU window.

Exit check
