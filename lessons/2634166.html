Facilitator’s Guide: RVR Robotics Overview

Four robot builds, one checkpoint, and a class of RVRs that have to be charged before any of it works.

Materials + prep

  • Sphero RVRs charged, and charged early. They do not come back from flat in a passing period. One robot per two or three students for most of the unit — but Talking with RVR needs at least two robots running at the same time, so plan that day around how many you actually have.
  • The Sphero Edu app or edu.sphero.com/code open and tested on a student device, with class code 4WDN5C confirmed still live before you teach Movement Blocks.
  • Markers and paper or butcher roll for the drawing runs, and a set of solid colour cards for the colour-sensor lesson.
  • Launch each assignment yourself once. The worksheets arrive through Google Assignments — the student’s copy is generated when they open the item from Canvas, so nothing needs distributing, but you should confirm the hand-back path works.
  • Xello through ClassLink for the closing check-in.

Watch-fors

  • The two “Learn:” items are interactive-lesson launches, not Canvas pages. They open in a new tab, and Learn: Seeing with the RVR shows an empty page in Canvas. That is normal. Say so before the first one or you will spend the period answering it.
  • The titles have no lesson numbers, on purpose. This unit’s original Lesson 1 — Biomagnification — now lives in Enrichment · Parked Alternates, so every number here would be off by one. The flow reads by name instead: Drawing → Movement → Seeing → Talking. If you want the biomagnification lesson, pull it out of Enrichment and teach it first; nothing in this module points at it.
  • Where this sits in the AIR arc. This is Unit 2. Unit 0 (Intro to AI) is over in SW4, and Units 1 and 3 — Leaving Land and Sailing Home — are elsewhere in SW5. Unit 3’s temperature-bot lesson assumes students have done this module, so run it before Sailing Home.
  • The checkpoint is a study loop, not a gate. It carries the most points in the module (10) and allows unlimited attempts. Point students back at Learn: Drawing with RVR between tries — that is the resource it is written from.
  • Movement Blocks asks for the most and is worth nothing. It is the only lesson that sends students out to the Sphero Edu platform, it collects answers and screenshots, and it is currently set to 0 points. Give it a value if you want that work in the gradebook.

Grading

The module carries 30 points as built. Checkpoint: Drawing with RVR is 10; Do: Drawing with RVR, Do: Seeing with RVR and Talking with RVR are 5 each; the Xello check-in is 5. Learn: Drawing with RVR, Learn: Seeing with the RVR and Movement Blocks are all set to 0. The three worksheet lessons come back through Google Assignments, so the completed worksheet is what you grade.
